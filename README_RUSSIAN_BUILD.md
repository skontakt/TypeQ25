# TypeQ25 Russian (photo) — собственная Android-сборка

Этот форк сохраняет оригинальные возможности TypeQ25 и добавляет раскладку **Russian Q25 (Photo)**, повторяющую русские надписи на физической клавиатуре с фотографии.

## Изменения
- `app/src/main/assets/common/layouts/russian_q25_photo.json`: 33 русские буквы на 27 клавишах, мультитап для Ё/Й, Щ/З, Х/Э, Д/Ж, Ь/Ъ, Б/Ю.
- Физическая крайняя правая клавиша Q25 (код Android 68) в этой русской раскладке вводит Б/Ю и использует стандартный MultiTapController. Для других раскладок и служебных комбинаций поведение валютной клавиши сохраняется.
- Исправлено отображение импортированных JSON-раскладок в настройках.
- Изменены имя и `applicationId` приложения на **TypeQ25 Russian** (`it.srik.TypeQ25.russianphoto`), чтобы его можно было устанавливать отдельно от оригинала.
- GitHub Actions собирает `debug` APK и загружает в Artifacts.

## Получить APK в GitHub
1. Откройте вкладку **Actions** этого репозитория и включите workflows (**I understand my workflows, go ahead and enable them**), если GitHub просит подтверждение (fork).
2. Перейдите к **Build TypeQ25 Russian APK** и выберите **Run workflow** после того, как изменения попадут в ветку `master`. Для ветки `feature/russian-q25-photo-apk` автоматическая сборка предусмотрена при push; PR в `master` также запускает сборку.
3. Откройте успешный запуск, прокрутите вниз до **Artifacts**.
4. Скачайте `TypeQ25-Russian-Photo-debug-APK`, распакуйте архив и установите `app-debug.apk`.

## Собрать локально
Нужны Android SDK с API 36, JDK 17 и интернет для Gradle-зависимостей.
- Windows: `gradlew.bat assembleDebug`
- Linux/macOS: `bash ./gradlew assembleDebug`

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## Настройка клавиатуры
После установки разрешите новую клавиатуру в настройках Android и выберите её в списке методов ввода. В TypeQ25 Russian выберите **Settings → Keyboard Layout → Russian Q25 (Photo)**. Для переключения раскладок используйте Ctrl+Space, если оно включено в настройках.

## Важное замечание
Изменения проверены по исходному коду и структуре JSON, но поведение устройства Q25 необходимо проверить непосредственно на телефоне — прежде всего код 68 и двойные нажатия. Отладочный APK подписан стандартным debug-ключом GitHub runner, а не релизным сертификатом. При следующей сборке на другом runner подпись может отличаться, и обновление поверх прежнего debug APK может потребовать переустановки приложения.
